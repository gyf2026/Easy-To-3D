# Versioned review

`review list --project <path> --submitted` reads saved batches. `review restore --project <path> --annotation <id>` returns source version and full view. `review claim --project <path> --version <id> --batch <id>` atomically returns a stable task ID; repeated claims reuse it.

Reconstruct camera position, target, up vector, projection/height or FOV, near/far and original aspect. Hidden objects and wireframe mode are part of the view. Review point is project mm, independent of camera transforms. Preview hash must match. Restore original geometry before interpreting local instructions or negations. Old-version review never automatically applies to current geometry.

Create `workspace create --project <path> --parent <source-version-id>`, then freely edit the model script. Validate changed and preserved dimensions. Reply with `review respond --project <path> --version <source-id> --batch <batch-id> --annotation <id> --text <explanation> --result-version <new-id>`. Use needs_clarification or unresolved with explicit reasons when not addressed. User original text is retained; Agent replies append. Subjective acceptance belongs to user.

Viewer submission only persists the batch. It displays a copyable continuation command; it does not claim to wake any client automatically. Later annotations form a separate batch. Concurrent saves fail with conflict; local drafts remain available for merge.

Line and ruler feedback may contain optional `markup`: `type` (line/ruler/freehand), `style` (solid; legacy dashed also supported), `units` (mm), `points_project` and corresponding `object_hints`. Line/ruler have two endpoints; freehand has 2–4096 ordered points. The anchor equals the first endpoint. Restore the saved view and interpret the ordered points together with the user's text; the line is a review overlay, not model geometry or an automatic modeling operation. Ruler length is Euclidean endpoint distance, not surface-path length or an independently verified manufacturing dimension. Ignore soft-deleted feedback for active work while retaining history. Submitted text, geometry and view are immutable; relocation creates a new draft.

Drawing starts on a visible model surface. Samples on geometry use surface ray hits; background samples are projected onto the camera-facing plane through the starting point and have object hint `view-plane`. They are not surface constraints. Straight lines preview continuously after the first click; freehand samples pointer movement while pressed. Escape discards an unfinished stroke, and completed strokes require feedback before persistence. The toolbar has no eraser: delete from the feedback list, retaining history.

Viewer feedback now uses an inline sidebar editor instead of a dialog. Markers appear immediately; empty text remains a local editing draft and must not be submitted to the server. Leaving a valid editor triggers automatic persistence. Browser drafts recover automatically; concurrent edits retain a separate conflict copy instead of overwriting. No manual save/reload/merge workflow is exposed. Historical comparison shows the selected model on the left and latest on the right with one shared camera; only the right/latest model accepts new feedback. Reference axes/grid are optional and off by default.
