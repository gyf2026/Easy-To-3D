# Security reports

Do not disclose credentials, private designs or exploitable vulnerability details in a public issue.

If the repository's **Security → Report a vulnerability** entry is available, use GitHub private vulnerability reporting. If it is unavailable, open an issue requesting a private contact channel without including technical exploit details or sensitive attachments. The maintainer can then establish a private reporting channel.

Easy-To-3D is Alpha software; no response-time or supported-version commitment is currently offered. The viewer is intended for local loopback use. Do not expose it as a public or multi-user service. Agent-written modeling scripts execute with the user's local permissions; review untrusted scripts before running them.
