# v0.1.0a3 — Alpha pre-release

Easy-To-3D v0.1.0a3 is an Alpha pre-release.

Easy-To-3D connects Agent-driven modeling with local 3D review: annotate a version, continue the work in your Agent, and compare the resulting revisions from a shared view.

## Changes since v0.1.0a2

Canvas panning:

- The marker toolbar adds a **Pan** tool beside **Browse**. With Pan active, a left-button drag (mouse) or a one-finger drag (touch) brings the target area to the centre of the view; **Browse** restores rotation and double-click feedback.
- Right-drag still pans while Browse is active, so both routes stay available.
- The history pane and the current pane keep sharing one viewing position: panning either side moves both, and both panes follow the same pointer behaviour. Panning never changes model geometry or annotation coordinates, and the selected tool survives camera replacement (projection switch, view presets, fit).
- The tool and its hint are translated for all four viewer languages (zh/en/ja/fr).

Saved-annotation deletion:

- Deleting an already-saved annotation is now written to the project. The save snapshot previously dropped deleted entries before the request, so removing a saved annotation could show in the browser but never reach the project file. Deleted entries keep their history and visible review numbers stay consecutive.

Documentation: viewer navigation is described in [user workflow](../user-workflow.md) and both READMEs; the verified scope is recorded in [compatibility](../compatibility.md).

## Included

- Local CLI, bundled browser viewer and structural-design Skill.
- FreeCAD/Blender reference workflows, explicit coordinate handling and static GLB/binary STL import.
- Version-bound comments, review batches, replies, user confirmations and synchronized comparison.
- Immutable project versions, backup verification, STL and drawing delivery workflows.

## Install

Install the wheel with `python -m pip install <downloaded-wheel.whl>` in a Python 3.10+ environment. Extract the Skill ZIP and load the `structural-design` folder using your client's mechanism. FreeCAD/Blender are separate installations. See [quick start](../quickstart.md).

Release attachments should contain only the wheel, source archive, Skill ZIP and `checksums.json`. The manifest records SHA-256 hashes of the three archives. Internal platform-validation bundles are not release attachments.

## Limits

Alpha quality. The viewer does not automatically wake an Agent. Client/model capability varies; see [compatibility](../compatibility.md). Canvas panning and the saved-deletion fix were verified in the local viewer regression suite on macOS with Chrome 155.0.8059.79 (36 viewer checks, including panning in both the current and history panes); Windows hardware has not been re-tested for these changes. build123d remains experimental. CAD feature history is not recovered from imported meshes. Printing suitability and patent drawing requirements require separate review. Public CI covers packaging/startup; full functional tests remain separately maintained.
