# v0.1.0a4 — Alpha pre-release

Easy-To-3D v0.1.0a4 is an Alpha pre-release. It changes how the structural-design
Skill is delivered; the workbench itself is unchanged.

## Changes since v0.1.0a3

Self-contained Skill:

- The Skill now carries the workbench runtime, the offline viewer and the JSON schemas inside `scripts/`, launched through `scripts/et3d.py`. Installing the Skill is sufficient: no `easy-to-3d` on `PATH`, no `pip install`, no network at first use. The launcher falls back to a source checkout while developing the workbench, and to an installed package only when no bundle is present.

Build identity:

- Every bundle carries `scripts/BUILD.json` with the runtime version, source commit, tag, working-tree state and a SHA-256 per source file. `et3d --bundle-info` prints that record together with the runtime actually loaded, so a user reporting a problem can name the exact code they ran.
- `tools/build_skill.py` gains `--check` (reports `fresh`, `stale`, `tampered` or `missing` for any existing bundle, exiting non-zero unless fresh), `--force`, `--install` (replaces a local copy after keeping a timestamped backup) and `--notes` (writes the upload card beside the zip). It refuses to build when `pyproject.toml` and `core/easy_to_3d/__init__.py` disagree on the version.
- A tag push now builds the Skill bundle in CI, verifies the stamp against the checkout, and attaches the zip to the release.

Documentation: [Skill release](../skill-release.md) records how the bundle is produced, how drift is detected and which step of publishing stays manual.

## Included

- Local CLI, bundled browser viewer and structural-design Skill.
- FreeCAD/Blender reference workflows, explicit coordinate handling and static GLB/binary STL import.
- Version-bound comments, review batches, replies, user confirmations and synchronized comparison.
- Immutable project versions, backup verification, STL and drawing delivery workflows.

## Install

Install the wheel with `python -m pip install <downloaded-wheel.whl>` in a Python 3.10+ environment. Extract the Skill ZIP and load the `structural-design` folder using your client's mechanism; the runtime is included. FreeCAD/Blender are separate installations. See [quick start](../quickstart.md).

Release attachments should contain only the wheel, source archive, Skill ZIP and `checksums.json`. The manifest records SHA-256 hashes of the three archives. Internal platform-validation bundles are not release attachments.

## Limits

Alpha quality. The viewer does not automatically wake an Agent. Client/model capability varies; see [compatibility](../compatibility.md). The packaged Skill was verified end to end on macOS (FreeCAD 1.1.4): init, modeling, publish, surface review, child revision, responses and STL export, plus 36 viewer checks in Chrome 153.0.8010.12 against the bundled copy. Windows hardware has not been re-tested for the packaged Skill. build123d remains experimental. CAD feature history is not recovered from imported meshes. Printing suitability and patent drawing requirements require separate review. Public CI covers packaging/startup; full functional tests remain separately maintained.
