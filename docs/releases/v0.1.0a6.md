# v0.1.0a6 — Alpha pre-release

Easy-To-3D v0.1.0a6 is an Alpha pre-release. It corrects what the Skill claims about
Windows and Python, and makes a wrong interpreter a one-line repair instead of an
unreadable failure. Geometry behaviour is unchanged.

## Correction to v0.1.0a5

The v0.1.0a5 notes said the packaged Skill had not been run on Windows hardware and
that only the CLI core had. That was wrong. The packaged Skill — launcher plus bundled
runtime — had been exercised on Windows with CPython 3.10 through 3.15. The v0.1.0a5
text is left as published, so the record of what was believed then stays intact; this
release is where the claim is put right for anyone reading the current one.

## Changes since v0.1.0a5

- `SKILL.md` states the supported range plainly: any CPython from 3.10 up, run on
  Windows with 3.10 through 3.15 and on macOS with 3.13. A newer interpreter is not a
  risk to warn about, and no third-party dependency has to be installed.
- The launcher refuses a too-old interpreter in one line: the version it was handed,
  the executable, and two examples of rerunning the same command with a newer one.
  Previously a 3.x below 3.10 died somewhere inside a module, which read like a broken
  skill rather than a wrong interpreter. The guard is deliberately written in syntax
  the old interpreter can still parse, since it is the one part that must speak on a
  runtime that cannot run.
- `SKILL.md` turns that refusal into an instruction: read the version, pick a newer
  interpreter the machine already has (`py -3.13`, `python3.13`, or the one your own
  runtime ships), rerun, and only involve the user when nothing 3.10+ exists.
- `references/environment.md` records the packaged-Skill Windows result next to the
  earlier CLI-core one, while keeping the limit that no single test covers every
  Windows build, architecture or tool configuration.

## Included

- Local CLI, bundled browser viewer and structural-design Skill.
- FreeCAD/Blender reference workflows, explicit coordinate handling and static GLB/binary STL import.
- Version-bound comments, review batches, replies, user confirmations and synchronized comparison.
- Immutable project versions, backup verification, STL and drawing delivery workflows.

## Install

Install the wheel with `python -m pip install <downloaded-wheel.whl>` in a Python 3.10+ environment. Extract the Skill ZIP and load the `structural-design` folder using your client's mechanism; the runtime is included. FreeCAD or Blender is a separate installation, and the Skill asks for its path when it cannot find one. See [quick start](../quickstart.md).

Release attachments should contain only the wheel, source archive, Skill ZIP, the
listing icon and `checksums.json`. The manifest records SHA-256 hashes of the
archives. Internal platform-validation bundles are not release attachments.

## Limits

Alpha quality. The viewer does not automatically wake an Agent. Client/model capability varies; see [compatibility](../compatibility.md). Without a local FreeCAD or Blender the Skill cannot produce new geometry; it can still review an existing mesh, import an external result and manage versions. The packaged Skill was verified end to end on macOS (FreeCAD 1.1.4) with 36 viewer checks in Chrome 153.0.8010.12 against the bundled copy, and its launcher plus runtime were run on Windows 10 with CPython 3.10 to 3.15. Neither covers every OS build, CPU architecture or CAD version. build123d remains experimental. CAD feature history is not recovered from imported meshes. Printing suitability and patent drawing requirements require separate review.
