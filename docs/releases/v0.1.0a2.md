# v0.1.0a2 — Alpha pre-release

Easy-To-3D v0.1.0a2 is an Alpha pre-release.

Easy-To-3D connects Agent-driven modeling with local 3D review: annotate a version, continue the work in your Agent, and compare the resulting revisions from a shared view.

## Changes since v0.1.0a1

Viewer lighting:

- The default illumination is now an upper-left key light that follows the current view, with soft hemisphere fill, so the back and underside stay readable while orbiting.
- A **Fixed lighting** checkbox in the right toolbar restores the previous world-fixed lighting. It is cleared by default.
- The history pane and the current pane share one lighting setting and one camera, so a same-view comparison is lit identically.
- The checkbox is a page-local display option. It is not stored in model versions, annotation views or cross-session preferences. Restoring an annotation view keeps the current lighting mode; select the same mode manually when comparing against older screenshots.
- No new runtime dependencies and no change to model data.

Documentation: lighting behaviour and its boundaries are described in [quick start](../quickstart.md) and [user workflow](../user-workflow.md); the verified scope is recorded in [compatibility](../compatibility.md).

## Included

- Local CLI, bundled browser viewer and structural-design Skill.
- FreeCAD/Blender reference workflows, explicit coordinate handling and static GLB/binary STL import.
- Version-bound comments, review batches, replies, user confirmations and synchronized comparison.
- Immutable project versions, backup verification, STL and drawing delivery workflows.

## Install

Install the wheel with `python -m pip install <downloaded-wheel.whl>` in a Python 3.10+ environment. Extract the Skill ZIP and load the `structural-design` folder using your client's mechanism. FreeCAD/Blender are separate installations. See [quick start](../quickstart.md).

Release attachments should contain only the wheel, source archive, Skill ZIP and `checksums.json`. The manifest records SHA-256 hashes of the three archives. Internal platform-validation bundles are not release attachments.

## Limits

Alpha quality. The viewer does not automatically wake an Agent. Client/model capability varies; see [compatibility](../compatibility.md). The new lighting interaction was verified on macOS Chrome 154.0.8037.99 (33 viewer regression checks plus 6 external textured-model checks) and has not been re-tested on Windows hardware. build123d remains experimental. CAD feature history is not recovered from imported meshes. Printing suitability and patent drawing requirements require separate review. Public CI covers packaging/startup; full functional tests remain separately maintained.
