真实后端包从官方下载，SHA256 校验；不随程序包分发。FreeCAD 首次从 dmg 加载动态库耗时较长，实际脚本须检查成功标记和产物，不能只信返回码 0。

Windows 实施与运行边界见 [跨平台说明](platform-support.md)，Agent 保存和打印操作见 [交付流程](agent-delivery.md)。真实用户项目已完成368文件备份及解压重开、4历史版本哈希核验与STL交付，原始验收记录由维护者本地保留；机器适用性仍为unknown。

Windows10 AMD64/Python3.13.14/Chrome153.0.8010.53修正版完整验证：114项核心全部通过，无跳过/失败/错误，含4项Windows专用测试；28项原有及6项外部模型/提交状态浏览器检查通过。FreeCAD1.1.4中文项目/脚本入口及Blender5.2.1 LTS建模、发布、STL、备份恢复通过。核心阶段使用2400秒时限，实际约1378秒；上轮300秒超时和队列等待错误的原报告仍保留，新结果来自完整官方验证入口。打印适用性、人工确认、Blender独立结构检查及宿主私有3D能力仍为unknown/not_run。诊断文件不随仓库分发。

当前支持自检缓存失效、Agent提供的分项客户端能力证据及需求路由指引，详见 [用户流程](user-workflow.md)。客户端私有接口自动探测仍由宿主Agent执行；核心不能独立证明云生成或局部编辑能力。

查看器导航修正已在macOS/Chrome154复测：加载提示收尾、鼠标位置缩放、右键平移、重建相机及历史画布操作；原28项浏览器回归扩展至32项（含指定语言刷新保持）。Windows上之前34项检查仍为修正前记录，新导航行为尚未在Windows复测。
