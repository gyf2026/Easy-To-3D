# 由 Agent 保存、备份与准备打印文件

用户直接在 Agent 对话中说：

> 请保存当前项目，备份整个工程，并为已确认的版本准备打印文件。先核验保存路径、版本和检查结果；需要机器专用文件时，先向我确认打印机与切片配置。

查看器负责模型检查和点评；无需先使用查看器导出。右上角支持中文（首次默认）、English、日本語、Français，选择保存在本机浏览器。界面即时切换，用户点评、模型名称与原始测量证据保留原文。

Agent 的入口是 `easy-to-3d --json delivery-guide --project <项目路径> --version <版本ID>`，可加 `--language en|ja|fr|zh`。返回绑定项目 ID 和版本的操作说明、逐条 argv 命令数组、独立备份及交付路径。直接以 argv 调用进程，不将用户路径拼进 shell；macOS 路径和 Windows 的 `C:\3DProjects\...` 都作为单个参数传递。

## 保存与备份

退出有效的点评输入后，点评自动写入项目；未完成输入暂留浏览器。模型工作区由 Agent 的建模脚本保存，发布后原生模型、脚本、需求快照及检查结果成为不可变版本。查看器显示“已保存”仅指点评，不能用它判断 Agent 建模脚本是否完成。

1. 检查项目、待处理点评及未完成工作区，确认需要保存的版本。先完成浏览器正在编辑的内容；浏览器本地未保存输入不会进入项目 ZIP。
2. 通过 `version verify` 核验发布文件；发生变化时先修复原因，不覆盖原版。
3. `easy-to-3d --json backup --project <项目路径> --output <工程外的新ZIP路径>` 保存整个项目，包含版本、原生文件、需求、点评、日志及既有交付。正在执行的项目拒绝备份，文件变化会使事务失败，旧备份不会被覆盖。
4. `easy-to-3d --json backup-verify --file <ZIP路径>` 按清单逐文件检查 SHA-256。恢复时先验证，然后解压到新目录，以其中的 `project` 目录打开项目；项目 ID 和相对资源路径保持不变。加密、网盘上传和自动备份调度不属于当前备份命令。

## STL 与打印机专用文件

`export --project <项目路径> --version <版本ID> --profile print --output <新交付目录>` 生成毫米 STL、打印说明、网格检查和版本哈希清单。输出目录必须新建或为空，并且不能在需求、工作区、历史版本等源文件区内。所有文件先在同一磁盘的临时目录生成、校验和刷新，再一次性提交；失败不暴露半成品，不覆盖已有交付。

Agent 核对 `manifest.json` 与 `print-checks.json` 后提供保存路径。网格有开放边、非流形边、异常法向、退化面或非正体积时，适用性为 fail；网格无已知问题但缺少材料/工艺检查时为 unknown，不能报告“已验证可打印”。不要把多个机械部件自动融合、加厚或修网格而改变用户设计。

STL 是切片输入。用户需要 G-code、BG-code 或厂商专用文件时，Agent 必须先取得实际打印机型号、固件、喷嘴、材料、层高和认可的切片器配置，检查热床范围、摆放、支持、壁厚和间隙。Agent 使用外部切片器实际提供的 CLI 或界面；本核心不自带切片引擎，也不预设任何打印机。

切片器缺失时，Agent 提出官方来源、版本、架构、安装位置和权限；经用户同意后自行下载安装、核验并重新自检。切片时保留输入和配置哈希、切片器版本、日志、输出与校验值，实际检查层预览、温度、运动/挤出范围及耗材。没有配置时交付已核验的 STL 并列出缺项，不猜测机器设置。文件准备不包含发送机器或开始打印。
