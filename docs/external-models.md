# 外部生成模型与客户端接入

Easy-To-3D可以承接客户端或外部3D服务生成的静态网格：本地模型导入 → 查看和点评 → Agent读取评审批次 → 修改或生成候选 → 导入子版本 → 比较与回复。核心不绑定云服务，不保存云API密钥，也不自动调用付费服务或上传模型。

## 已核对的接口与能力边界

核对日期：2026-10-10。

- 腾讯官方提供WorkBuddy安装 `hy-3d-generation` 技能的入口；这是通过技能接入3D服务，不等于客户端通用对话模型自带精确CAD能力。[官方入口](https://cloud.tencent.com.cn/act/pro/moltbotandai)
- 混元生3D专业版接口接受文字/图片，可输出带纹理模型，默认结果包含GLB/OBJ，也可指定STL等格式。默认面数500000，文档范围3000–1500000；该服务范围不等于本查看器已验证容量。[生成接口](https://cloud.tencent.com/document/api/1804/123447)
- 已有模型可以用于纹理生成；输入GLB/OBJ并不证明支持按三维标记局部修改几何。[纹理接口](https://cloud.tencent.com/document/api/1804/126292)
- 官方接口目录还包含拓扑、组件、UV、格式转换及动画相关能力。本次未找到可据以保证“输入原模型、三维选区及点评，修改局部并保持其他结构”的几何编辑合同。客户端实测时仍需发现实际可用接口，状态保持unknown。[接口目录](https://cloud.tencent.com/document/api/1804/120825)、[格式转换](https://cloud.tencent.com/document/api/1804/126300)

WorkBuddy的账号权限、技能版本、模型下载和图片传递需要在目标客户端实测；本机样例测试不代替客户端通过。

本地验证：macOS实际Chrome已通过嵌入PNG贴图/UV/PBR、多primitive部件定位、点/线点评保存与历史对比。另以130048个三角面、65026个顶点的合成网格验证导入、发布及实际鼠标点评；这只是已测样例，不代表所有复杂模型或150万面模型均可流畅处理。新版wheel在Python3.10安装后完成导入、发布及点评交接。Windows10/Chrome153也已通过6项外部模型及提交状态浏览器检查。WorkBuddy执行本地验证包不等于其私有3D生成或局部编辑接口已验收；这些接口仍待实测。

## 文件接入

直接支持自包含、未压缩的静态GLB及二进制STL。GLB保留材质、贴图、UV、法线、节点变换和层级；只为预览节点补充确定的部件ID，不改原文件。多primitive对象和重名节点可稳定点评。STL没有材质信息。

压缩网格、GPU实例化、KTX2/Basis纹理、骨骼、动画、变形目标、稀疏几何及外置资源当前不直接支持。遇到这些文件，由Agent用已有Blender等工具导出自包含静态GLB，保留原文件和转换脚本；不把不支持的属性悄悄删掉。OBJ/FBX也先经外部工具转换。不同格式转换后的坐标、比例及外观必须核对。

[glTF标准](https://github.com/KhronosGroup/glTF/blob/main/specification/2.0/Specification.adoc)规定米及Y-up，但实际生成文件仍应核对提供方和尺寸；导入必须显式声明，不能凭数值猜单位。生成资产的视觉比例不等于用户需要的打印尺寸。

```sh
easy-to-3d --json import --project <project> --source <local-model.glb> --units m --up-axis Y
easy-to-3d --json version publish --project <project> --workspace <returned-workspace-id> --summary 外部模型初稿
easy-to-3d view --project <project> --version <published-version-id>
```

由Agent填入实际路径和ID，用户无需编辑JSON。模型下载由客户端完成，不把短期URL当作持久版本文件。原始文件、哈希、导入单位轴向和需求快照保存在项目内；不能从网格恢复未知CAD历史。

## 点评交接与修订

用户提交点评后，Agent读取确切版本与批次：

```sh
easy-to-3d --json review handoff --project <project> --version <source-id> --batch <batch-id>
```

该操作只读取，不领取任务或发起远程调用。输出包括原始模型与预览路径/哈希、点评原文和编号、点/线/曲线、部件提示、完整视角、源版本需求快照、mm/Z-up项目坐标及原文件坐标、双向变换矩阵，以及领取、接收子版本和回复的argv。可作为客户端Agent的输入，不应把JSON直接当作云服务请求体。

1. Agent先恢复原版及点评视角，判断是几何、纹理还是尺寸要求。能力不清楚时检查实际服务的输入合同。
2. 支持局部几何编辑时调用相应接口；否则可用Blender修改网格。只有纹理接口时不能声称几何已改好。重新生成时明确是新候选，并检查被要求保留的结构。
3. 云上传、账号配置和费用遵循用户授权；无权限时可继续本地编辑，不在聊天或Git中存密钥。
4. 返回文件导入为**点评源版本**的子版本，不能自动以当前最新版本为父版本。handoff内给出正确variant和parent参数。
5. 发布前核对改变及保留约束，发布后逐条回复，恢复同视角比较。旧点评不自动迁移到新网格，原意见及旧文件不变。用户决定接受。

## 交给WorkBuddy的实测指令

> 请读取本项目 docs/external-models.md，并加载新版 structural-design Skill。复用已有3D生成技能和安装环境，先确认你能保存本地静态GLB及读取图片/执行本地命令。生成一个可辨认方向、带材质的小型模型，下载到项目外的本地文件，核对单位和上轴，再通过Easy-To-3D导入并发布初稿，打开查看器供我点评。不要调用额外付费服务或上传已有私人模型，除非得到我的授权。
>
> 我提交点评后，请使用review handoff读取源版本和批次。核对实际3D服务是否支持局部几何编辑；不能把纹理修改或全量重新生成写成局部修改成功。必要时用已有Blender进行网格编辑。保留原模型，把返回结果导入为点评源版本的子版本，检查改动和未改区域、发布并逐条回复，打开同视角对比。记录每步pass/fail/unknown及实际接口/客户端版本。

客户端验收应覆盖材质显示、mm定位、点与线点评、原版视角恢复、一次可核对的局部修订、旧版文件完整性和逐条回复。原始生成能力、精确修改能力及打印适用性分别判定；首次成功导入不等于全部通过。
