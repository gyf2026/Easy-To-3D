# 规范与实施决策

设计基线为维护者本地保留的开发计划 v0.3.2；该过程文件不随仓库分发。独立工程，不导入或修改 EasyTo3D 历史代码。

- 本地核心使用 Python 3.10+ 标准库，避免用户为打开项目安装数据库。查看器用固定 Three.js 0.180.0 ES 模块，本地随包分发；开发源暂为 JavaScript，TypeScript 属计划建议而非验收条件。
- 协议 1.0：右手坐标、Z 向上、mm；矩阵 row-major，平移在 3/7/11。原生建模预览以 m、Y-up 储存；外部 GLB 保留其声明的源单位与上轴，通过 preview_to_project 显式转换。所有拾取存回项目坐标，不猜单位。
- 原子 JSON 替换、操作系统自动释放的跨进程锁、评审修订号。一个版本一份评审聚合记录，事件与当前状态在同一原子事务中更新，避免双文件部分提交。
- 发布模型、脚本、依赖与需求快照不可变。review 是可变追加区；用户接受状态独立保存。历史环境变化不表示产物损坏。
- 本地 HTTP 仅回环地址、精确 Host、同源 Origin、随机 CSRF token，写入必须 If-Match。无任意命令执行端点。
- 原生有效性、重建性、需求符合性与网格检查分开报告。候选版本可以有未知检查，不能称为验收通过。
- 初始数值容差：GLB 尺寸核对 0.01 mm，STL 往返 0.01 mm，检查焊接 1e-6 mm。真实鼠标点击按一个像素误差核验（当前标定构图约 0.1 mm）；数学坐标与相机往返使用 1e-9 数值容差。本机 M5/16GB、Chrome 软件渲染下，100352 三角形预览已测：温页面加载约32ms、恢复约16ms、30帧平均约34ms。首版同设备目标：≤10万三角形加载2秒内、恢复200ms内、平均帧时50ms内；其他设备需重测，性能原始记录由维护者本地保留，不随仓库分发。
- FreeCAD 为首选机械路线，Blender 第二路线；build123d 仅对照实验。真实运行成功后才写入支持矩阵。
- 默认不遥测、不云存储、不切片、不生成 G-code。用户于2026-10-08确认代码采用 Apache-2.0，许可原文随发行包分发。
- 当前核心适配目标为 macOS/Windows；Linux 尚未实测。跨平台设计约束：项目协议与几何/评审逻辑不依赖系统路径或进程机制；后端程序路径可配置；文件锁、进程身份、取消与清理等系统差异集中在基础设施模块，后续可替换为平台实现。项目内资源使用相对路径；不因缺少某平台能力而伪报成功，也不提前承诺未实测平台支持。

- 用户于2026-10-09明确：缺失工具时提供 Agent 代下载与安装流程，在用户同意具体来源、版本、位置及权限后执行，完成后进行真实启动/脚本/导出探测。自检缺失结果本身不构成安装授权。

- 2026-10-09 用户最新要求核心至少适配 macOS/Windows，实现与实测分别标注，详见 platform-support.md。Agent 为保存与打印交付主入口；核心导出 STL，机器专用切片由 Agent 在取得明确配置后操作外部切片器。

- 客户端生成、几何编辑、纹理编辑和本地下载分别保留证据；未知能力不推断通过。精确结构优先CAD，外形和网格任务按已验证能力选择路径。自检缓存限时并随工具变化失效，模型校验和用户确认独立。

- GLB检查拒绝GPU实例化等未实现的几何扩展，即使该扩展不是required；避免浏览器显示多个实例而检查和STL仅处理基础网格。需要先用外部工具展开实例，保留原文件及转换记录。
