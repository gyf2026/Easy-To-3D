# 通用客户端安装

1. 在用户本地安装 Python 发行包，按实际需要安装 FreeCAD 或 Blender。
2. 将 structural-design 技能目录放到客户端支持的位置，加载其 SKILL.md。客户端的技能位置、执行权限与图像传递能力须实测。
3. 在当前会话完成真实识图与无副作用执行测试，先轻量自检，再仅对本次需要的后端运行实际脚本导出探测。
4. 查看器回环 URL 可由普通浏览器打开。提交批注后复制一条接续指令发给原 Agent 会话。

Codex 当前开发会话已用于实现和本地调用，但插件安装与自动唤醒没有实测包装，因此不宣称已支持。项目所有者已确认WorkBuddy和豆包正常使用（2026-10-10）；具体版本及逐项能力尚未完整归档，其他客户端仍待验证。基础 Skill 不要求 MCP。

WorkBuddy等客户端已有外部3D生成技能时，按[外部模型接入](../../docs/external-models.md)导入本地GLB、提交点评、读取review handoff并接收子版本。生成接口和局部编辑接口分别验收；不把本地样例通过写为目标客户端已通过。

首次使用及需求路由请遵循 [Agent 引导流程](../../docs/user-workflow.md)：轻量自检后只探测本次需要的后端；客户端能力分项实测，未知不等于缺失。保存和打印优先通过 Agent 对话完成。
